# Proyecto Hotel El Dorado

Proyecto nuevo y separado del módulo sanitario "El Túnel" (ver `../el-tunel-el-dorado/`).
Este es el hotel que se va a construir sobre un terreno con levantamiento topográfico real.

## Levantamiento topográfico (recibido)
Archivo: `topografia/PROYECTO_HOTEL_EL_DORADO_topografia.pdf`
Empresa: GIGAR Inversiones, C.A. — Asesoría Minera
Cajetín: Topografía Keilin R. · Dibujo Luis G. · Revisado Michelangelo C. · Aprobado (pendiente)

Es una imagen escaneada/rasterizada (no un CAD vectorial con puntos de coordenadas
exportables), con:
- **Coordenadas UTM:** Norte 742452 a 742472 (20 m) · Este 650258 a 650283 (25 m)
- **Área de construcción:** delimitada en rojo, cubre casi todo el paño levantado
- **Curvas de nivel:** de 139,1–139,2 (zona norte) a 139,6–139,9 (zona sur) — el
  terreno sube levemente hacia el sur, desnivel ≈ 0,5–0,8 m en el fondo del lote

## Pendiente para avanzar
- No hay puntos de coordenadas exportables (XYZ) — si el topógrafo tiene el
  levantamiento en CAD/Excel con los puntos crudos, conviene pedirlo para poder
  triangular curvas de nivel con precisión en vez de leerlas del PDF a ojo.
- Definir programa del hotel (cantidad de habitaciones, áreas comunes, estacionamiento)
  antes de proponer distribución sobre el terreno.
- Decidir si el hotel se distribuye en una sola planta o varios niveles, dado el
  desnivel del terreno.
